# A near meeting is not a common point

This is a modern experiment inside the existing I.1 course, not another room.
Its question is narrow: does making two side readings agree provide the point
that Euclid next tells the reader to join?

J. L. Heiberg, _Euclidis opera omnia_, vol. I (Leipzig: Teubner, 1883):

The [Toronto volume](https://archive.org/details/euclidisoperaomn01eucluoft)
identifies the edition and scan. Those four retained page images were visually
inspected for this change. The new panel reuses the course's existing full
passages, English readings, vocabulary annotations, source viewer and byte

In the Greek relative clause, **καθ᾽ ὃ τέμνουσιν ἀλλήλους οἱ κύκλοι** identifies
the point by the circles cutting one another. Heiberg's Latin has **in quo
circuli inter se secant**. Postulate 3's drawing command does not explicitly
state a circle-intersection condition. The panel asks a modern question about
that difference; it makes no claim about the history of continuity axioms.
The source viewer preserves the complete pages and apparatus.

## Keep one constraint exact

Set Α = (0,0), Β = (1,0), with radius 1 at each centre. Admit only points with
two rational coordinates. A parameter t = m/n supplies

```text
x = (n*n - m*m)/(n*n + m*m)
y = 2*m*n/(n*n + m*m)
```

The first squared distance is exactly 1 by the identity
`(n*n - m*m)^2 + (2*m*n)^2 = (n*n + m*m)^2`. The second is calculated from
`(x-1)^2 + y^2`, with signed residual

```text
BP^2 - 1 = (3*m*m - n*n)/(m*m + n*n)
```

BigInt fractions decide circle membership; floating point is used only for
screen position and explicitly approximate length displays. The exact audit
shows squared distances so it need not approximate a square root.

The eight approach presets alternate sides and reduce the absolute residual.
A custom candidate need not follow that sequence; its button therefore says
**Start candidate sequence**, rather than promising a closer result.

square root. The unrestricted argument does not rest on these examples.

## Why the restriction excludes the meeting

A common point must satisfy both circle equations. Subtracting gives x = 1/2;
substitution gives y squared = 3/4. Thus the real-plane intersections are
(1/2, ±sqrt(3)/2), neither of which has two rational coordinates.

If sqrt(3) = a/b in lowest terms, a squared = 3b squared. A square has remainder
0 or 1 modulo 3, so 3 divides a. Substitution then makes 3 divide b too,
contradicting lowest terms. This excludes every rational height, not merely the
candidates within the input bounds. Rational t can approach 1/sqrt(3)
arbitrarily closely, and its coordinate formulas are continuous there, so
arbitrary closeness is compatible with the absence of an admitted meeting.

This restricted point experiment does **not** claim to verify every Euclidean
postulate or definition in the rational plane. Other constructions fail there
as well. The continuous dashed circles are expressly real-plane guides, not
rational curves with their missing points silently filled. The optional hollow
diamonds reveal both real intersections without moving P onto one of them.

## State and saved readings

The normalized experiment is independent of the course plate's changing size,
orientation and reflection. It uses nonnegative whole m up to 1,000,000 and
positive whole n up to 1,000,000. These are interface bounds, not a limitation
on the impossibility argument. Invalid form input leaves the current candidate
and its share link intact. Invalid shared pairs fall back together to 11/19.

`im`, `in`, `ip` and `ir` to the existing bounded state hash. Navigating away
hides the panel; browser Back restores the former experiment.

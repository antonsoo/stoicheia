# Equal leftovers, unequal shapes

The fourth room gives the proof behind the extra-square relation in II.14.
It pairs an experiment in I.43 with the complete I.43 and II.5 readings, then
follows the original gnomon diagram instead of leaving II.5 as an unexplained
formula.

## What can be learned

Move Κ along the diagonal and shear the parallelogram. Its two complements
keep equal areas. Then choose **Try an off-diagonal point**. The blue and green
areas become 7.35 and 25.35 square units, while each pair of small diagonal
triangles remains equal. The failure is precise: those small diagonals no
longer partition the two large halves along ΑΓ, so the proposed subtraction
does not apply.

Restore Κ and follow the four stages. The proof uses I.34 three times, then
subtracts equal totals from equal wholes. Shape matching is unnecessary.

The second experiment applies that equality in II.5. With lengths 9 and 4,
the complements each have area 10. Three common additions lead to a rectangle
of area 36, an equal gnomon, and finally the whole square of area 42.25.
The missing 6.25 square is the same excess exposed by the II.14 workshop.
The link to II.14 carries the chosen lengths into that construction.

The complete proofs have eighteen aligned Greek/Latin/English units, language
notes and four questions. Ten source scans preserve the repeated conclusions
and critical apparatus. The source's duplicated Μ is explained explicitly:
Μ remains a boundary point, and ΜΝΞ names the L-shaped gnomon. Heiberg's own
footnote records the ambiguity and an alternative he did not adopt.

## Evidence

- **Geometry:** [25,205 complement configurations and 22,801 rectangle inputs](gnomon-oracle.json)
  independently checked with exact rational areas, coordinate shoelace areas
  and a separate diagonal-line intersection. Every named II.5 region is checked.
- **Real workflow:** [Chromium and Firefox at 1440 and 375 pixels](gnomon-browser.json).
  Keyboard controls, broken and restored hypotheses, all stages, all eighteen
  readings, questions, source zoom, history, shared settings, real SVG/CSV/HTML
  downloads and local reopening. Actual SVG polygon-area ratios are compared
  with the expected areas. The saved scans match their manifest hashes and its
  embedded CSV matches the separate download. Reviewed views have no axe
  violations, page errors, console errors or external runtime requests.
- **Offline:** the same local workflow physically disables its HTTP origin,
  independently confirms the origin is unreachable, visits all four rooms and
  saves another complete reading. Hosted browser offline mode is a separate,
  weaker observation and does not control the public origin.
- **Edition upgrades:** [held and substituted source requests in both engines](gnomon-upgrade.json).
  The previous three-room edition remains usable after a failed replacement.
  The current edition is not ready until complete; recovery permits all four
  rooms and the exact new scan with the origin disabled.
- **Downloads:** [snapshot and recovery probes](gnomon-exports.json) hold a
  source while the live lengths change, substitute a different scan with HTTP
  200, require no download, and retry successfully. These direct-fetch probes
  remove service-worker capability before startup; the separate offline and
  upgrade reviews test worker behavior.
- **Layout:** [414 diagram configurations](gnomon-layout.json) across both
  engines and three widths, including extreme shears, off-diagonal points,
  thin rectangles, near-equal cuts and equal limits. Point-label intersections,
  SVG clipping and page overflow are checked. The visual review also opened
  the desktop, phone, counterexample, gnomon, source and printed views.
- **Print:** [all 72 complete paragraphs](gnomon-print.json) of Greek, Latin,
  English and notes survive PDF text extraction. Poppler's layout mode preserves
  the printed hyphen in “half-length”; its default extraction dehyphenates that
  wrapped word. Source-page margins and the two complete area tables were
  inspected in the rendered PDF.
- **Development:** [the same four workflows](gnomon-development.json) make no
  service-worker requests and clearly identify development mode. The shared
  offline guard also permits normal reading when that API is unavailable.

The export probe exposed a real layout defect before release. Without dimensions
on the lazy source image, its arrival moved the Save button by about 385 pixels
on desktop and 523 on a phone, and Firefox could miss the click. Reserving the
image's actual dimensions reduced the measured shift to zero in both engines.
[Negative-control and repaired measurements](gnomon-source-layout.json).

## Reproduce

```sh
npm ci
npm run check
npm run verify:gnomon
node scripts/gnomon-browser.mjs /tmp/gnomon-browser
node scripts/gnomon-upgrade.mjs OLD_THREE_ROOM_DIST dist /tmp/gnomon-upgrade.json
node scripts/gnomon-exports.mjs http://127.0.0.1:4327/stoicheia/ /tmp/gnomon-exports
node scripts/gnomon-layout.mjs http://127.0.0.1:4327/stoicheia/ /tmp/gnomon-layout.json
node --import tsx scripts/gnomon-print.ts /tmp/gnomon-browser/chromium-1440/reading.pdf
```

The external-URL commands expect a running preview server. `npm run check`
includes formatting, strict TypeScript, 47 checks and the production build.
